# npmjs-ror

Read-only copy of `ror`, the RunOnRoad client for a workstation, published to npm as [`@runonroad/ror`](https://www.npmjs.com/package/@runonroad/ror).

- This repository is written only by the release of `ror`: each `ror-v*` tag copies the client and a reduced API contract here, then publishes the signed package with npm provenance.
- Do not open issues or pull requests here: changes are made in the RunOnRoad source repository and copied on the next release.
